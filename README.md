# ✊ Rock Paper Scissors

A modern and responsive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The application allows users to play the classic game against the computer by choosing **Rock, Paper, or Scissors**. It features real-time score tracking, instant result updates, and an engaging user interface, making it a fun and interactive project for beginners learning JavaScript.

## 🚀 Features

* ✊ Choose Rock, Paper, or Scissors
* 🤖 Play Against the Computer
* 🎲 Random Computer Moves
* 🏆 Real-Time Score Tracking
* 📢 Instant Win, Lose, or Draw Results
* 🔄 Restart Game
* 🎨 Modern & Clean UI
* 📱 Fully Responsive Design
* 🚀 Lightweight and Beginner-Friendly

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
